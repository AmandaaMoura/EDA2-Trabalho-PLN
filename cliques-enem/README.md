# projeto-cliques-enem

Estrutura inicial do projeto para análise de cliques e grafos sobre textos do ENEM.

## Pastas
- data/raw/: textos originais coletados
- data/processed/: corpora preparados para análise
- src/: implementação do pipeline
- results/: gráficos e tabelas geradas
- docs/: documentação adicional
- presentation/: material de apresentação
